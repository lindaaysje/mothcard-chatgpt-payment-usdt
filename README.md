## 二、挡在中间的那一层

### 链路长什么样

OpenAI 自己不收加密货币。ChatGPT Plus、Pro、API 的每一笔扣款，走的都是 Stripe。

Stripe 收到的是一串卡号和一组上下文信息，它要在几十毫秒里同时看很多项，判断这笔授权放不放：卡号前几位对应的发卡机构和发卡国、你的 IP 所在地、你填的账单地址国家、卡是不是预付卡、能不能走 3DS 验证。

这些项里有一项是**硬性的**，其余是加权的。硬性的那一项就是**发卡地**。

### 发卡地为什么是硬性的

对某些发卡地，Stripe 这一层有区域性规则，整类不放行。OpenAI 自己的帮助文档也写了这个意思——付款人和发卡机构都需要位于受支持的地区，任一方不在，付款就可能被拒。

多家第三方排查指南的结论是一致的：香港发卡的卡在 OpenAI 这条链路上属于处理器层面的拦截，不是银行层面的。落到你这边看到的现象就是：卡好好的，钱也够，但订阅页面就是过不去。

这一层和你的操作完全无关：

| 你试过的 | 有没有用 |
|---|---|
| 多充钱 | 没用，不是余额问题 |
| 换卡组织 | 没用，不是屏蔽维度 |
| 换 IP、换设备、换浏览器 | 没用，发卡地改不了 |
| 挂代理到美国 | 没用，反而可能更糟（下面会讲） |
| 找免实名的卡 | 和这个无关 |

因为它根本不是在判断"这个人可不可信"或者"这笔钱够不够"，而是在判断"这串卡号是从哪儿来的"。一张卡的发卡地是写死在卡号里的，你改不了。

所以这个问题的正确问法不是"我该怎么绕过去"，而是——**换一张发卡地能通过的卡**。
关于哪些发卡地会被拦、为什么会被拦，MothCard 官网有一篇更完整的拆解：[为什么你的虚拟卡在 AI 订阅上会被拒](https://www.mothcard.io/zh-CN/blog/why-virtual-cards-get-declined-on-ai-subscriptions/)。

### 另外那些加权项，也会咬你

发卡地是门槛，过了门槛之后，其余几项会决定成功率：

- **IP 和账单地址国家不一致**，是最常见的加权扣分项。拿一张某国发的卡配一个完全无关的 IP，风控会当作异常
- **账单地址格式不对**，账单地址与发卡地不一致，会引起报错
- **3DS 走不通**，验证该弹没弹、或者弹了没完成，授权就挂在那里

## 三、这些流传很广的说法，是怎么来的


**"要用免实名的卡。"**

免实名的卡通常来自那些不做 KYC 的小平台，而这类平台为了能让用户真的刷出去，往往会去找非主流地区的发卡渠道。所以有人用免实名的卡付成功了，真正起作用的是那张卡的发卡地，不是"免实名"这个属性。

反过来，免实名的卡里也有大量付不了 ChatGPT 的，因为它恰好是被屏蔽的发卡地。

**"要高权重卡段。"**

"卡段权重"这个词，它想描述的现象是真的——同样是虚拟卡，有些就是比别的好用。

用"权重"这个词去描述它，问题在于它暗示这是个能花钱买到的等级，于是人们去找"更高权重"的卡，而不是去看发卡地和卡性质。方向一开始就偏了。

**"要换成 Visa"（或者反过来）。**

这条通常来自一次具体的成功经历：某人换了张卡成功了，而那张卡刚好是另一个卡组织的。

但那张卡同时也换了发卡地。变量没分离开，于是归因给了卡面上最显眼的那个 logo。

**"挂美国 IP 就能过。"**

这条不只是没用，有时候是反作用。

风控会比对你的 IP 和账单地址国家。如果你用一张某国发的卡，却从一个美国节点提交，这个组合本身就是异常信号。免费或共享的 VPN 节点风险评分普遍偏高，被整段标记的情况也有。

正确的做法恰恰相反：**让 IP 和账单地址对上**，而不是刻意伪装成另一个国家。

### 和那批停服的平台，区别在哪

过去两年里，野卡、Dupay、bingo card、fomecard 接连停止服务。剧本几乎一模一样：先是提现变慢，然后客服不回，然后官网打不开，最后电报群禁言。留在卡里和账户里的余额，大多没拿回来。

这导致现在选卡，第一个问题不再是"费率多少"，而是"这家会不会也跑"。

MothCard 和那批平台有两处结构性的不同：

**第一，需要 KYC。**

停服的那批普遍主打免实名。这两件事是有关联的——不做 KYC 通常意味着没有合规框架，也就没有一个可追责的主体。出事的时候你找不到人。

免实名让开卡变快，让受限地区也能用卡，这很好。

但 MothCard 也很快——最快1分钟，你就能拿到卡，且大部分卡都允许受限地区申请。

**第二，六张卡分属不同的发卡通路。**

这是比费率更值得看的一项。

如果一个平台只有一条发卡通路，那条通路出问题就是平台全停跑路——用户自己在社区里总结过这句话，"所有虚拟卡都逃不过上游影响"。

这个判断对单通路平台是成立的，而  MothCard 是多通路平台，比单通路更有保障。

### 回到 ChatGPT：发卡地在这里是决定性的

不少同类产品的介绍文章会把"香港发卡"当作对 ChatGPT 友好的卖点来写。按我们的实测，这个说法在 AI 订阅这个具体场景上不完全成立——香港发卡在这条链路上并不万能。它在海淘、机酒、流媒体上确实好用，但 AI 是个例外。

## 六、从注册到付款，一步一步来

以 Glow 为例。整个流程大概十分钟。


### 第 1 步 · 注册

点击邀请链接，用邮箱注册，下载 MothCard App。

### 第 2 步 · 完成 KYC

提交基础身份信息，最快 1 分钟过。

**一个常见的被拒原因：姓名和证件不一致。** 别把名字"整理"成更顺眼的拼法，别调整姓和名的顺序，别省略中间名。照着证件上印的逐字填。这是各类卡平台 KYC 被退回最高频的原因，和平台本身没关系。

别担心，你属于任何地区，都可以进行KYC。

### 第 3 步 · 申请 Glow

在卡列表里选 Glow，开卡费 $10，预存 $10。

注册后你的账户里会有一张 **$5 开卡抵扣券**，30 天有效。用上之后开卡实付 $5。

**这一步要有点耐心**：Glow 是审批开卡，不是提交就出卡。等审核结果出来再操作，中间不要反复提交申请。

### 第 4 步 · 充 USDT 进钱包

App 内钱包支持 USDT 三条链：

| 链 | 说明 |
|---|---|
| **TRC20** | gas 最低，日常就用这条 |
| **Polygon** | 费用也低，适合资产本来在 Polygon 上 |
| **ERC20** | 以太坊主网 gas 偏高，小额充值不太划算 |

### 第 5 步 · 从钱包划转到卡

这一步最容易被跳过，也是最常见的"为什么刷不了"。

MothCard 是钱包和卡两层：链上转进来的钱先落在**钱包**里，这时候卡里的余额还是零。要消费，得再做一次**划转**，把钱从钱包移到具体某张卡上。

这个设计的好处是你不用一次性把钱都押进卡里，想花多少划多少，剩下的留在钱包。

### 第 6 步 · 在 OpenAI 绑卡

这是最后一步，也是最容易在这儿摔的一步。按顺序做，不要跳。

**付款前先做三件事：**

**① 检查 VPN 和代理。**

风控会比对你的 IP 和账单地址国家，Glow 是新加坡发卡，你如果从一个美国节点提交，这个组合本身就是异常信号。

**② 账单地址填新加坡。**

Glow 是新加坡发卡，账单地址要和发卡地对上。
随便填一个其他国家的地址，大概率会充值失败。

**③ 确认卡里余额够。**

订阅扣款是**含税**的，实际扣款会比标价高一点。

**然后开始绑卡：**

1. 登录 ChatGPT，进升级页面
2. 填卡号、有效期、CVV
3. 账单地址按发卡地填
4. 提交
5. 如果弹出 3DS 验证，看 MothCard App 的推送通知，按提示完成。

**如果被拒了，最重要的一条：不要连续重试。**

每次失败都可能被记成一次可疑交易，连续失败会触发临时锁定，把问题变复杂。

**还有一条备用路径**：网页端反复不行的话，可以试试把卡加进手机钱包，然后从 ChatGPT 的移动 App 里订阅。这条路由走的是 Apple 或 Google 的扣款体系，和网页端直接提交卡号不是同一条链路。

### 第 7 步 · 管好续订

这一步没人提，但它决定你三十天后会不会突然掉回免费版。

ChatGPT Plus 每 30 天自动扣一次。如果扣款那天卡里余额不够，续订失败，OpenAI 会在接下来几天重试一两次，一直失败就会把账号降回 Free。

对话历史不会丢，但 Plus 的功能没了。

两个办法，选一个：

- 卡里常备 $25～$30，别让余额见底
- 在日历上设一个每月提醒，比扣款日提前三天去充

补充一句：**订阅不用了记得解绑。** 授权一旦发生就会产生费用，这件事在冻结卡之后依然成立。
